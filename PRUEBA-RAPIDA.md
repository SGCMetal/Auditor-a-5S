# Lista de prueba rápida

- [ ] Se puede seleccionar cualquiera de las 11 áreas.
- [ ] Cada pregunta permite hasta 5 fotografías.
- [ ] Las fotos permanecen al avanzar y regresar.
- [ ] Al terminar aparece la pantalla de evidencia general.
- [ ] Se pueden cargar hasta 5 fotografías generales.
- [ ] El resultado conserva la calificación elegida por la auditora.
- [ ] Las recomendaciones se pueden editar u ocultar.
- [ ] La auditoría aparece desde otro dispositivo.
- [ ] Se puede publicar el portal de evidencias.
- [ ] El QR se descarga como PNG.
- [ ] El QR abre únicamente la vista de evidencias.
- [ ] El portal permite enviar evidencia opcional de mejora.
- [ ] La evidencia opcional aparece en el detalle interno.
- [ ] El Excel contiene la hoja “Evidencias y QR”.
