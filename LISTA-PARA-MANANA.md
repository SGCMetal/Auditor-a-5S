# Lista para dejarla lista antes de la primera auditoría

## Esta tarde

- [ ] Crear el proyecto `mps-auditoria-5s` en Firebase.
- [ ] Registrar la aplicación web.
- [ ] Copiar `firebaseConfig` dentro de `config.js`.
- [ ] Habilitar **Authentication > Anónimo**.
- [ ] Crear Firestore en modo de producción.
- [ ] Publicar las reglas de `firestore.rules`.
- [ ] Agregar el dominio de GitHub Pages a los dominios autorizados, si hace falta.
- [ ] Subir esta carpeta a GitHub Pages.

## Prueba de 10 minutos

- [ ] Abrir la app en el celular de la auditora; no debe pedir correo ni contraseña.
- [ ] Escribir el nombre de la auditora.
- [ ] Realizar una auditoría de prueba de un área.
- [ ] Capturar al menos una fotografía.
- [ ] Presionar **Guardar y sincronizar**.
- [ ] Abrir la misma app en la computadora del Coordinador del SGC.
- [ ] Confirmar que la auditoría aparezca en **Historial**.
- [ ] Abrir la auditoría y comprobar la fotografía.
- [ ] Exportar el Excel.

## Mañana antes del recorrido

- [ ] Confirmar batería y conexión del celular.
- [ ] Abrir la app y verificar que diga **Sincronizado**.
- [ ] Confirmar el nombre de la auditora.
- [ ] Eliminar o identificar claramente la auditoría de prueba.
- [ ] Mantener el enlace de la aplicación únicamente dentro de MPS.
